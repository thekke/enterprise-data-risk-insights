# Enterprise Data Risk Insights

## Overview
This project is a SQL Server and Power BI case study that demonstrates how enterprise data risk information can be consolidated into executive-level insights.

The dashboard integrates synthetic datasets covering applications, data risks, controls, control testing, incidents and remediation actions.

## Business Problem
Senior risk and technology leaders need to understand:
- Where data risk is concentrated
- Which themes and controls are driving risk exposure
- Which remediation actions require management attention
- Whether the underlying risk data is reliable enough for reporting

## Tools Used
- SQL Server
- T-SQL
- Power BI
- Data modelling
- Risk analytics
- Data quality checks

## Dashboard Pages
1. Executive Overview
2. Risk Themes & Controls
3. Remediation & Data Quality

## Key SQL Outputs
- Executive risk summary
- High residual data risks
- Control effectiveness
- Risk theme analysis
- Overdue remediation actions
- Management attention items
- Data quality checks

## Data Note
The dataset is synthetic and created for portfolio demonstration purposes. It mirrors common fields used in technology risk, data risk, control testing, incident management and remediation reporting.

## Key Insights Demonstrated
- Weighted risk exposure scoring
- Executive RAG classification
- High residual risk identification
- Control weakness analysis
- Overdue remediation ageing
- Data quality issue detection
- Management attention prioritisation
